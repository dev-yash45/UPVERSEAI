# UPVERSE AI 🏛️✨
> **AI-Powered Travel & Cultural Intelligence Portal for Uttar Pradesh**

UPVERSE AI is a modern, responsive web application designed to showcase the heritage, culture, spiritual landmarks, and hidden gems across all 75 districts of Uttar Pradesh. Powered by intelligent AI planning, interactive maps, and a dynamic theme system.

---

## 🌟 Key Features

- **🤖 AI Trip Planner**: Generates personalized, day-by-day travel itineraries based on destination, travel style, budget, group size, transit mode, and culinary preferences.
- **🧭 75 Districts Directory**: Fast search with alias matching (e.g. `lko`, `rbl`, `kashi`), category filters (Historical, Religious, Nature, Food, Popular), and instant suggestions.
- **🏛️ District Deep Dive**: Detailed exploration of history, cuisine, festivals, hidden gems, live image galleries, and interactive Leaflet map integration.
- **💬 Ask UPVERSE AI**: Real-time AI consultation answering specific travel, cultural, and logistics questions for any district.
- **🎨 Dynamic Theme Engine**: Smooth toggle between Sacred Saffron Dark Mode and Sleek Modern Light Mode with persistent user preferences.
- **📱 100% Fully Responsive**: Pixel-perfect UI optimized for all devices from 320px mobile screens to large desktop monitors.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via a local server:

```bash
# Using Python
python3 -m http.server 8080

# Using Node / npx
npx serve .
```

Navigate to `http://localhost:8080` to experience UPVERSE.

## 🛠️ Built With

- **HTML5 & Vanilla CSS3**: Custom design tokens, glassmorphism, responsive fluid typography, and micro-animations.
- **JavaScript (ES6+)**: Modular client-side controllers, API integration, and offline-resilient fallback generation.
- **Leaflet.js**: Lightweight interactive maps with custom location pins.
- **Font Awesome & Google Fonts**: Cinzel, Poppins, and Inter typography.
